Introducción

Programar es darle instrucciones precisas a una computadora para resolver un problema. Un programa es una receta: los ingredientes son los datos y los pasos son las instrucciones.

Ruta de estudio: primero la lógica (Parte 1), luego el paradigma de objetos (Parte 2) y finalmente construimos aplicaciones con ventanas en Visual Studio (Parte 3). Los ejemplos usan C#.

Algoritmos y diagramas de flujo

Un algoritmo es una secuencia finita y ordenada de pasos para resolver un problema. Debe ser preciso, finito y con resultado esperado. Se representa con pseudocódigo o con diagramas de flujo.

Estructuras condicionales

Permiten que el programa tome decisiones según una condición.

int nota = 75;
if (nota >= 90) Console.WriteLine("Excelente");
else if (nota >= 60) Console.WriteLine("Aprobado");
else Console.WriteLine("Reprobado");

switch (dia) {
  case 1: Console.WriteLine("Lunes"); break;
  default: Console.WriteLine("Otro"); break;
}

Ciclos (bucles)

Repiten un bloque de código. Usa for si conoces el número de repeticiones y while si depende de una condición.

for
Contador conocido
while
Evalúa antes de ejecutar
do…while

Recorre colecciones
for (int i = 1; i <= 5; i++)
    Console.WriteLine($"2 x {i} = {2 * i}");

int suma = 0;
while (suma < 10) suma += 3;

Arreglos y listas

Un arreglo guarda varios valores del mismo tipo; se accede por índice, que empieza en 0.

int[] notas = { 8, 5, 9, 2, 7 };
Console.WriteLine(notas[2]); // 9
foreach (int n in notas) Console.WriteLine(n);

List<string> nombres = new();  // tamaño dinámico
nombres.Add("Ana");

Funciones (métodos)

Un método agrupa código reutilizable. Recibe parámetros y puede devolver un valor.

static double CalcularArea(double baseT, double altura)
{
    return baseT * altura / 2;
}
double a = CalcularArea(4, 3); // 6
Tip: usa void cuando el método no devuelve nada. Un método debe hacer una sola cosa y tener un nombre claro.

¿Qué es la Programación Orientada a Objetos?

La POO modela el software como objetos del mundo real que tienen datos (atributos) y comportamientos (métodos). Sus cuatro pilares:

Abstracción
Modelar solo lo importante.
Encapsulamiento
Proteger los datos internos.
Herencia
Reutilizar clases base.
Polimorfismo
Un mismo método, varias formas.

Clases y objetos

La clase es el molde (plano); el objeto es una instancia concreta creada con new.

public class Estudiante
{
    public string Nombre;
    public int Carnet;

    public Estudiante(string nombre, int carnet) // constructor
    { Nombre = nombre; Carnet = carnet; }

    public void Saludar() => Console.WriteLine($"Hola, soy {Nombre}");
}
Estudiante ana = new Estudiante("Ana", 1001);
ana.Saludar();

Encapsulamiento

Los datos se declaran private y se exponen mediante propiedades que pueden validar valores.

ModificadorAcceso
publicDesde cualquier lugar
privateSolo dentro de la clase
protectedClase y clases derivadas
public class Cuenta
{
    private double saldo;
    public double Saldo { get => saldo; }
    public void Depositar(double monto)
    {
        if (monto > 0) saldo += monto; // validación
    }
}

Herencia

Una clase derivada reutiliza los miembros de una clase base con la sintaxis : Base. Relación "es un".

public class Persona { public string Nombre; }
public class Estudiante : Persona { public string Carrera; }

Polimorfismo

Permite que objetos de distintas clases respondan al mismo método de forma diferente, usando virtual y override.

public class Animal { public virtual void Sonido() => Console.WriteLine("..."); }
public class Perro : Animal { public override void Sonido() => Console.WriteLine("Guau"); }
public class Gato : Animal { public override void Sonido() => Console.WriteLine("Miau"); }

Animal[] zoo = { new Perro(), new Gato() };
foreach (var a in zoo) a.Sonido(); // Guau, Miau

Visual Studio de Microsoft

Mini proyecto: Calculadora de IMC

Integra variables, condicionales, métodos y controles. Controles necesarios: 2 TextBox (txtPeso, txtAltura), 1 Button (btnCalcular) y 1 Label (lblResultado).

private void btnCalcular_Click(object sender, EventArgs e)
{
    if (!double.TryParse(txtPeso.Text, out double peso) ||
        !double.TryParse(txtAltura.Text, out double altura) || altura <= 0)
    {
        MessageBox.Show("Ingresa valores numéricos válidos.");
        return;
    }
    double imc = peso / (altura * altura);
    lblResultado.Text = $"IMC: {imc:F1} - {Clasificar(imc)}";
}

private string Clasificar(double imc)
{
    if (imc < 18.5) return "Bajo peso";
    if (imc < 25) return "Normal";
    if (imc < 30) return "Sobrepeso";
    return "Obesidad";
}
Reto: crea una clase Persona con propiedades Peso y Altura y un método CalcularIMC(); usa un objeto en el botón en lugar de variables sueltas.
